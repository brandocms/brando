What was verified

The full run and targeted follow-ups leave no unresolved failures: 197 enabled tests passed, with 12 authorization-mode-specific checks intentionally skipped. Read the full E2E result record.

  • Intake & replacementImage validation, Cancel/retry, queued replacement after Remove, file/video replacement, and per-use settings after save/reopen.
  • CollectionsMixed image/video/image ordering, resource-gallery save, gallery-variable save, selection and deselection.
  • Existing flowsCrop/copy/replacement, variable uploads, entry image variables, file-field synchronization, library upload/replacement, populated video listing, and modal navigation.
  • Build & smaller testsE2E consumer build; Elixir compilation/formatting; nine AssetIntent tests; four progress-projection tests; diff whitespace check.

Remote S3/provider transfers were not exercised with live credentials. Provider hooks, generated-copy transport and form-remount attachment recovery retain their existing boundaries. The work does not add Undo, Retry or partial acceptance of unsupported mixed batches. This is local implementation. The default E2E configuration skips 12 authorization-mode-specific checks; other consuming applications were not tested.
