- Connected AI tools can add an image to the media library over MCP: `brando_media_prepare_upload` gives a one-time upload URL for the file's bytes (`curl -T photo.jpg <url>`), `brando_media_finish_upload` stores them, and `brando_media_import_url` imports one from a public `https` address. Both reuse an image the library already has, and take a focal point (given, or copied from another image), a title and alt text. Tools already connected can use them too; the consent screen lists adding images among what a tool can do.
