- An image is marked as on the CDN once its original and every size, with each size's other formats, are uploaded, in one job per image: before, an image whose upload of one size failed or was cancelled was never marked, with `keep_local_copy: false` its other files had already been removed from the media folder, and sizes in a second format (WebP, AVIF) were never uploaded. A failed upload now keeps the image's local files and is retried as a whole.
  Images already on the CDN have only their first format in the bucket. With `keep_local_copy: true`, Utilities → Recreate image sizes uploads the rest; with `keep_local_copy: false` the other formats were never kept, so upload those images again.
