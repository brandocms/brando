- `rsync_targets` and `s3_targets` also take a map from site key to that site's destinations, such as `%{"acme" => ["s3://acme-www"], "beta" => ["s3://beta-www"]}`, so a destination not named by the site key can be bound to one site; a site the map does not name gets none, checked on save and at deploy as the list is. `mix brando.doctor` and the System check warn, with several sites, about list entries without `{site_key}`, which grant every site, and map entries of two sites that reach one destination, and about a setting no target can pass.
