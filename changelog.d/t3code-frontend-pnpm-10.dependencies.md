- The generated frontend builds with pnpm 10.32.1 and Jupiter `5.0.0-beta.19`
  ([#3191](https://github.com/brandocms/brando/pull/3191)).
  In an existing application, set `"packageManager": "pnpm@10.32.1"` in
  `assets/frontend/package.json`, run `pnpm install` in `assets/frontend` and commit the lockfile.
