- Spaces between inline elements, such as `<strong>A</strong> <em>b</em>`, are kept by footnote
  rendering, Markdown export, search text, caption text and transfer previews, and are no longer
  lost when a rich text link to an entry is updated, a footnote marker is remapped or content is
  imported.

- An inline SVG's `viewBox` keeps its case in a field rendered with footnotes.

- Markdown export keeps the indentation of a code block that opens the document.
