- A page's canonical link, `og:url`, alternates and JSON-LD `@id`s and `url`s now name one URL without a trailing slash, however the page was requested (`/about/`, a query string, a static build), whatever order the controller calls `put_meta/3`, `put_json_ld/3` and `put_hreflang/2` in, and with one alternate in the page's own language: `@id`s are `https://example.com/about#webpage`, no longer `…/about/#webpage`, and the items of a datasource block's `json_ld` are `…/news/a#article`, the `@id` the entry's own page gives it. Which entry gives the page its URL is in the meta guide's "Canonical URL"; `put_page_url/2` sets another.
  Entries keep the old `@id`s in the JSON-LD their blocks stored until they are rendered again: run `mix brando.entries.resave --yes`, then restart the server or use Configuration → Cache → Empty all caches.

- The 404 and 410 pages, and other error responses, get no canonical link, `og:url` or JSON-LD `WebPage` node, which named the requested path (on a static build, the build's probe path for every missing page).
