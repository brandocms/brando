- **Forms, dialogs, drawers and sign-in use the shared button.** A form's
  Save is `.btn--lg .btn--save`; modals, drawers, the settings screens
  (sites, publishing, environments, shared library, Markdown sources,
  security), the login, password and two-factor screens and the fields' own
  actions move from `primary`, `secondary`, `tertiary` and `tiny` to `.btn`.
  The context stylesheets drop the rules that restyled those classes.
