- On a multi-site installation each site uses its own languages and default language, in the admin and on the public side, and `Brando.Languages` reads them; provisioning or editing a site refuses a language `config :brando, :languages` lacks, and changing its default language syncs its identifiers.
  In a hand-written sitemap module, pipe each language's entries through `Brando.Sitemap.in_site_languages/1` before `url/1`, so a site's sitemap leaves out other languages.
  Read the content languages in your own code with `Brando.Languages.languages/0` and `Brando.Languages.default_language/0` instead of `Brando.config(:languages)` and `Brando.config(:default_language)`.
  On a multi-site installation, give every language your router has localized routes for a prefixed scope, the installation's default language included (`scope "/en", as: :en`): the unprefixed routes are each site's default language's. `Brando.I18n.Helpers.localized_path/3` logs a warning for a missing one.
