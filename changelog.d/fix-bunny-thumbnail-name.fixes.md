- A Bunny video's poster and admin thumbnail no longer break after a custom thumbnail is set in Bunny: they use the name Bunny stores, **Fetch details** for the selected videos in the video library picks up a changed one, and `Brando.Release.refresh_bunny_videos()` does that for every ready Bunny video.
  On a server: `bin/my_app rpc "Brando.Release.refresh_bunny_videos()"`. Stored pages take the name when they render again; `mix brando.entries.resave` (`bin/my_app rpc "Brando.Content.Resave.run()"`) renders every entry, and the 0.55 upgrade runs it.
