- A source-controlled `belongs_to` relation of a synchronized Blueprint that points at another schema with language links now follows the source onto the related entry's version in the translation's language (one already in that language is used as it is), and shows as awaiting translation while there is none; a new translation then has no such entry, or the source's when the relation is required. Before, the source's own entry was copied. Other `belongs_to` relations, and a page's parent, behave as before.
- `trait :translatable, matched_by: [...]` names the attributes an entry's language versions share; an unlinked entry with them in a language counts as its version there. `always_source_controlled: [...]` lists fields that are source-controlled in synchronized mode whatever the application configures.
