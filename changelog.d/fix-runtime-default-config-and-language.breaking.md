- A `default_config` under `Brando.Images`, `Brando.Videos` or `Brando.Files` changed in configuration, in `config/runtime.exs` too, takes effect without recompiling Brando: Brando's own assets and every Blueprint field with `cfg: :default` or a partial `cfg:` are merged with the value configured when they are read, and a `srcset` entry naming a size that value no longer gives is left out, with a warning in the log.
  A project that sets `default_config` in `config/runtime.exs`: run `mix brando.doctor`, and for each field Image srcset sizes lists, add the size to `default_config` or to the field's own `sizes`.
  Then recreate the images of fields whose sizes or formats changed with Configuration → Utilities → Recreate changed images (Image configs in `mix brando.doctor` counts them).
