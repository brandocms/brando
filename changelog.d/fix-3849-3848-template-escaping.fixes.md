- A string a `for` loop reads of a list of strings, the list assigned or not, is escaped once in a tag argument that escapes what it prints, as the string passed directly is: `{% for tag in entry.tags %}{% picture entry.cover { alt: tag } %}{% endfor %}` no longer prints `R&amp;amp;D` for `R&D`, and the same holds for `{% route %}`, `{% route_i18n %}`, `{% editable_field %}` and `{% inspect %}`, also given an assigned list itself. A value assigned from a variable that was set from a literal (`{% assign q = label %}` after `{% assign label = "A&amp;B" %}`) reaches those arguments as the literal does.

- `{% editable_field %}` and `<.editable_field>` print a rich-text field sanitized, as `{{ }}` prints it: markup the sanitizer removes (an event handler, a script) no longer reaches the page through them. A field only named forms draw as rich text prints as rich text there too, as with `{{ }}`.

- In frontend edit mode, a subform row's field that a template prints through its owner (`{% editable_field entry.items[0].text %}`) shows as it is typed by the owner's subform, as the page printed it, not by the row schema's own forms.
