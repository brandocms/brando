- With group authorization, saving a static site's deployment settings, its SSH key and host keys, and the review of the target's files take the new Configure permission on Builds & deployments (`brando.publishing.configure`); Build, Deploy and Schedule no longer give them, and the Publishing screen shows those without it the builds and a summary of the settings, without the target, its URLs or a build's log. `brando_249` gives Configure to every group that has Build, Deploy or Schedule, including groups that had only Build or Schedule, which reach the SSH key and the target's files with it.
  Run `mix brando.gen.migrations` for `brando_249`, then `mix brando.migrate` before the new release starts: until it has run, only superusers can change these settings.
  In a release, run `bin/my_app eval "MyApp.ReleaseTasks.migrate()"` from the new release.
