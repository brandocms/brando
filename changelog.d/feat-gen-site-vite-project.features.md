- On a multi-site installation, `mix brando.gen.site --site KEY` creates the site's own Vite project in `assets/sites/KEY/`, from the same templates as `assets/frontend`, building into its `dist/`, and adds the `.gitignore` and `.dockerignore` lines that keep each site project's `node_modules` and `dist` out of Git and the Docker build context; an existing folder is kept.
