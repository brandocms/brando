- The site's scripts run in an opaque origin in live previews: `localStorage`, `sessionStorage` and `document.cookie` keep values in memory only, and module scripts, fonts and `fetch` calls load cross-origin, which `Brando.Plug.SiteAssets` allows for the site's static files.
  Keep `plug Brando.Plug.SiteAssets` right before the endpoint's `plug Plug.Static` (`mix brando.migrate55` adds it). A preview script that fetches from the site's own routes needs `Access-Control-Allow-Origin` on them; with the Vite dev server, allow any origin in `server.cors`. Purge a CDN's cached static files once after deploying, so it stops serving copies without the header.
