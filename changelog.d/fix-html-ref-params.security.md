- Only superusers change the markup of HTML and SVG refs, so an editor can no longer save script that runs with the cookies of whoever views the page or its preview: an HTML ref is a template a superuser writes, with named, typed parameters (`id`, `number`, `url`, `text`) that editors fill in and that are checked and escaped on render. The server holds every save, content transfer, AI translation and content assistant proposal to this, and to the ref types the module defines. Existing HTML refs render as before, as templates without parameters.
  A project parser that overrides `html/2` should return `Brando.Villain.Blocks.HtmlBlock.render(data)` instead of `data.text`. Editors who maintained HTML or SVG refs need a superuser to change them, or to declare parameters for what they change.
