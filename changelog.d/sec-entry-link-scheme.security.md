- Addresses editors type render as links only with a scheme rich text allows (`http`, `https`, `mailto`, `tel`, `sms`, `ftp`, `ftps`, `callto`, `cid`, `xmpp`, or none): a `javascript:` or other address in a link var, `entry_link`, the `link_url` filter, a picture's link, a navigation menu item (its own address or its entry's external link), an identity service or a map block renders without an `href` or `src`, and the Markdown export leaves it out.
  Links that used another scheme (`webcal:`, `whatsapp:`, `geo:` and the like) lose their address too: check menus, link vars and picture links that use one.
