- An rsync deploy target must be a remote `[user@]host:/absolute/path` on another server: local and home-relative paths, `localhost` and loopback addresses, `..` in the path, `rsync://` and `host::module` targets, and users or hosts starting with `-` are refused when saved and when a build deploys, and rsync gets `--` before its operands. An operator can limit deploys to the destinations listed in `config :brando, Brando.Sites.DeployConfig, rsync_targets: [...]`.
  If a site's rsync target is a local directory or a relative remote path, change it under Admin → Config → Publishing to an absolute path on the static host (`deploy@static.example.com:/srv/www`), then rebuild: builds made before the change keep their old target and will not deploy.
