- A Mux video's **Quality** can play an MP4 static rendition (270p up to 2160p) instead of the stream, as Bunny videos can: new Mux uploads ask for 720p and 1080p renditions (`config :brando, Brando.Videos, mux_static_renditions: [720, 1080]`), and a video offers the ones Mux reports ready.
  Existing Mux videos stream until they have renditions: run `mix brando.videos.mux_renditions` to list the ones that lack them, then `mix brando.videos.mux_renditions --apply` to ask Mux for them. In a release, run `bin/my_app rpc "Brando.Videos.Uploaders.Mux.add_static_renditions()"` on the running node.
