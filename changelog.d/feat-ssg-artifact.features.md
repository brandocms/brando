- A static build holds what a static host needs to serve the site on its own: `404.html`, `robots.txt`, the built environment's sitemap, each page's Markdown alternate the application serves and `_redirects.json`, the site's redirects in a host-neutral list; the build's log notes what it left out, such as an alternate the application answers with 404 or the error page of a site whose catch-all answers every path.
