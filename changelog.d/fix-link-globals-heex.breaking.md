- In a HEEx module template, a link global in `@globals` is its `Brando.Content.Var`, not its URL string. Printing it, in text or an attribute, still gives the URL, and one with no address is still `nil`.
  Run `mix brando.doctor`: under Link globals in HEEx it lists the templates that use one as a string (`<>`, `String` functions, a comparison, a component attribute such as `<.link href={...}>`). Wrap each in `Brando.Villain.Filters.link_url/1`.
