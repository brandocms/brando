- `mix brando.doctor` warns when a development or test library ships in the release: Tidewave, which runs code for coding agents (an error when a production release has it loaded), and test libraries such as ExMachina, which installers before 0.55 added to every environment with the factory under `lib/`.
  Give Tidewave `only: :dev` and plug it inside `if Mix.env() == :dev` in the endpoint. Limit test libraries to the environments your tests run in (`only: :test`, or `only: [:test, :e2e]` with an e2e environment), move `lib/<app>/factory.ex` to `test/support/`, and make sure `elixirc_paths/1` adds `"test/support"` for those environments.
