- `mix brando.doctor` warns when a test library such as ExMachina ships in the release. Installers before 0.55 added ExMachina to every environment, with the factory under `lib/`.
  Limit the dependency to the environments your tests run in (`only: :test`, or `only: [:test, :e2e]` with an e2e environment), move `lib/<app>/factory.ex` to `test/support/`, and make sure `elixirc_paths/1` adds `"test/support"` for those environments.
