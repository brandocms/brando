- A host whose IPv4 or IPv6 lookup timed out, whose name server failed, or whose answer was cut short is no longer admitted to the served hosts file on the other family's addresses alone, and shows **Could not look it up** on the Environments screen with the family and the reason until a later check reads both, instead of **Does not resolve** for a lookup that was only slow.
  The served hosts check now asks the name servers in `/etc/resolv.conf` itself and does not read `/etc/hosts` or platform-specific resolver configuration; an installation whose hosts resolve only through those sets
  `resolver: Brando.Tenant.ServedHosts.SystemResolver` in `config :brando, Brando.Tenant.ServedHosts`.
  Code that reads `Brando.Tenant.ServedHosts.status/0` or its broadcast matches the new host state `{:lookup_failed, failures}` (each unread family and why).
