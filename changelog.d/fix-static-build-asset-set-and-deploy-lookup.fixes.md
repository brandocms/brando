- A static build renders its pages with the asset set it recorded when it was queued (or the release's own files when it recorded none), so a set activated before it runs no longer leaves its HTML linking files the artifact does not hold; a build whose recorded set was deleted fails and publishes nothing.
- Saving a site's rsync deploy target no longer waits on DNS while the form is used: the host is looked up on a save that sets the strategy or target (not one that changes only other settings), in the hosts file and then DNS, with one 3-second limit and the answer kept for a minute. A name DNS says does not exist still passes; a name server that fails or refuses, or a lookup that runs out of time, refuses the save, and the deploy, instead of passing it.
