- **Blocks move without dragging.** A block's menu has "Move up" and "Move
  down", for root blocks and for the children of containers, multi modules
  and regions. They send the same reposition a drag does, so the move is in
  the entry's next save and reaches the other editors in the entry the same
  way. The first block's "Move up" and the last one's "Move down" are
  disabled.
