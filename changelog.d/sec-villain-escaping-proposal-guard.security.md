- The Villain parser escapes the class, id, anchor, link and embed addresses it puts into attributes of headers, maps, videos, galleries, lists, text styles and sections, and leaves out header links and map embeds with a script or unknown scheme; the `{% link %}` tag escapes its address and renders an empty `href` for a script address.
- Content assistant and MCP proposals check what they write as untrusted text: string variables take plain text, text and html variables and entry fields safe rich text, link variables and slot links a web, mail or phone address or a path, map slots an https Google Maps embed address, slot settings no markup, and no value an opening brace (which could open a Liquid tag when the page renders). A failing value is an `:unsafe_text` problem, which blocks approval; a proposal with any problem shows no page preview and cannot be shared, and a proposal stored before the upgrade is checked again when it is approved.
- An unresolved entry link in proposed rich text no longer skips the safety check for the rest of the text.
