- A static site made from now on lets its Editor group view, build and deploy its builds, so editors put their changes online without configuring how the site publishes.
  On an existing site, tick Build and Deploy for the Editor group under Users → Groups to let its editors publish.

- Groups prepared for the switch from legacy roles give Editor View, Build and Deploy on builds and deployments on every site, so the editors of a static site can publish it after the switch.
  To keep it as in legacy mode, untick them for each site's Editor group under Users → Groups.
