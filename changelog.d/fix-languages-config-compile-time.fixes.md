- Adding a language to `config :brando, :languages` (or `:admin_languages`, or changing a `default_config` under `Brando.Images`, `Brando.Videos` or `Brando.Files`) now recompiles a Brando installed from Hex or Git on the next start, so the `language` field accepts the new language instead of failing with `Ecto.ChangeError`.
  These keys are compiled in: set them in `config/brando.exs`, not `config/runtime.exs`. A runtime value that differs from the compiled one stops a release at boot, and `Brando.System.initialize/0` raises naming the key and `mix deps.compile brando --force`.
