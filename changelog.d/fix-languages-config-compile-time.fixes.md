- Adding a language to `config :brando, :languages` or `:admin_languages` now recompiles a Brando installed from Hex or Git on the next start, so the `language` field accepts the new language instead of failing with `Ecto.ChangeError`.
  `:languages` and `:admin_languages` are compile-time configuration: set them in `config/brando.exs` or `config/config.exs`. A release whose `config/runtime.exs` sets them to anything other than what was compiled, including a project that sets them only there, stops at boot with Elixir's message ("the application :brando has a different value set for key :languages during runtime compared to compile time"), so move them out of `config/runtime.exs`. Under Mix, `Brando.System.initialize/0` stops boot when the codes differ and names `mix deps.compile brando --force`.
