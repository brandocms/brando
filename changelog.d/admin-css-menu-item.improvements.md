- **Menus share one row, `.menu-item`.** The rows of the row and export
  menus, the Save menu, the entry toolbar's More menu, saved views, block
  menus, the field AI menu, the image, video and gallery action menus, the
  media menus, the identifier picker, note mentions, the rich-text editor's
  popovers and inline select options all use `.menu-item` from `Menu.css`:
  32px, sentence case, a muted icon, `--danger` and `--ai` looks, a hint at
  the right edge and `.menu-separator` between groups. Rows no longer have a
  rule between each other, and the mono uppercase action lists are gone.
