- A value passed through `assign` to a tag argument that escapes what it prints is escaped once, as the field passed directly is: `{% assign q = entry.title %}{% picture entry.cover { alt: q } %}` no longer prints `&amp;lt;` in the alt text, `{% route %}` and `{% route_i18n %}` build the address from the text as typed (`it's` gave another path), and `{% editable_field q %}` and `{% inspect q %}` escape it once. `{{ q }}`, every other tag option, an expression on the variable (`q.size`) and an assign that starts from a literal (`{% assign q = "A&amp;B" %}`) print as before.
- `{% video %}`'s svg cover takes `opacity`, `width` and `height` only as numbers (or text holding one), and falls back to the default opacity and the aspect ratio's size otherwise: a field passed there could break out of the cover's markup. The `<video>` element gets `width` and `height` as written, as before (`width: "100%"`).
- The comment `{% form %}` prints for a form that is not published escapes the key, so a key cannot close the comment.
